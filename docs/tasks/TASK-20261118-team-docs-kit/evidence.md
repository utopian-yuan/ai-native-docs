## E1

2026-11-18，Codex，T1 / AC1、AC4。验证对象为从基线 `ae8bd98` 开发并提交为 `c9e34fc` 的首版文档，环境为 macOS 和 `/bin/sh`。从 README 提取两个 shell 代码块，仅替换模板仓库的路径，在两个独立临时目录中运行。用启用遇错退出的 shell 检查每一步的返回状态。

| 输入与操作 | 实际结果 |
| --- | --- |
| 空项目接入，建一个 FEAT，再次接入 | 创建了根规则、客户端入口、空白变更日志和四件套模板；再接入时跳过七个已有文件。生成的工作项恰好四份 Markdown，其相对链接在目标项目中有效 |
| 已有项目预置自己的 AGENTS、CLAUDE、CHANGELOG 和任务模板，再执行接入与建项 | 四个原文件逐字保留，缺少的文件补齐。新工作项沿用了该项目自己的任务模板 |
| 给新建任务写入认领内容，重复运行建项命令 | 目录已存在时命令返回非零，已有认领记录保留 |
| 检查复制后的 AI 入口 | CLAUDE.md 导入同目录的 AGENTS.md；根规则引用的模板和日志均可定位。此次核对到文件和引用，未逐一启动编码客户端 |

初次走查发现本机的 `cp -n` 跳过已有文件时会返回非零，中断启用了遇错退出的接入流程。README 改为先检查目标文件，再复制缺少项，上述两种场景均已重跑。
