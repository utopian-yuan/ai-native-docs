## 目标与范围

从 EDTQ 提炼团队可以迁入其他代码仓库的 Markdown 协作方式。项目发起人确认范围，Codex 负责编写和本地验证；团队成员需能共用一套记录并查到个人交付。

| 编号 | 验收条件 |
| --- | --- |
| AC1 | 在新项目按 README 接入并建出一个四件套；已有项目执行相同步骤时，同名规则和已有工作项内容得到保留 |
| AC2 | 从新成员入口能找到任务主状态、分工、交接和证据；示例覆盖负责人移交及一次失败后复验 |
| AC3 | 按贡献者账号能找到其独立和共同交付，并从每条示例 CHANGELOG 追到该次工作项、证据和版本 |
| AC4 | 根 AGENTS.md 给出可执行的协作规则，Claude Code 入口引用同一文件，其他客户端有显式读取方法 |
