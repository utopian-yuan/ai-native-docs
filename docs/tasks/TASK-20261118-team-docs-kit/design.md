# 首版设计取舍

| 决定 | 采用的做法 | 原因 |
| --- | --- | --- |
| 一个工作项目录多人维护 | 保留主状态、方案、分工、证据四种职责；任务和证据使用可引用的编号 | 独立分支合并后，接手人仍能沿同一组路径找到上下游 |
| 记录实际贡献 | 根 CHANGELOG 分列交付时的负责人和贡献者，相邻修订各自成条 | 可以区分负责、实施和代提交，交接后仍能追溯旧版本 |
| 指令可移植 | AGENTS.md 只引用接入步骤会复制的文件；专用客户端引用根规则 | 目标项目保有自己的技术栈、命令和工具选择 |
| 教学材料与实际交付 | CSV 案例的评审、证据、CHANGELOG 集中在 examples；本仓库维护记录用真实工作项 | 复制空白模板时可以得到干净的起点，也能回看完整案例 |

本项目仅提供 Markdown 约定、模板和示例。字段含义和人的决定由团队在开发与评审中核对。
