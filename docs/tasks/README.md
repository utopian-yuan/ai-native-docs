# 工程工作项

基建、内部升级、治理、联调、部署或文档体系建设使用 `TASK-YYYYMMDD-slug/`，从 [四件套模板](../_templates/README.md) 起步。可按工程目标自定义 AC，写清产物、版本或环境和操作结果。

| 工作项编号 | 工程目标 | 上下游资料 |
| --- | --- | --- |
| 添加工作项链接 | 写明可交付的结果 | 关联路线图、依赖、契约或运行手册 |

数据专项可从 [data/tasks](../data/tasks/README.md) 接续。需要收存的完成或取消任务进入 [工程任务归档](archive/README.md)。
