# 工程任务

治理、迁移、构建、发布准备或跨团队交接可以作为 TASK。用交付物定义完成条件，例如另一位同事能用指定输入重放结果，或者旧配置能从备份恢复。负责人写清产物位置、使用人、操作步骤和适用环境。

| 使用方法 | 入口 |
| --- | --- |
| 看一份已填好的工程任务 | [候选版四单冒烟样本](TASK-20260512-example-filter-smoke/change.md)，含固定输入、重复准备检查和发布人员的独立复做 |
| 查样本为何从整表变成四行 | [已取消的方案](archive/TASK-20260508-example-queue-snapshot/change.md) |
| 建新的任务或查已关闭任务 | [工作项模板](../_templates/README.md) · [工程任务归档](archive/README.md) |

本模板仓库自身的真实开发工作随[交付日志](../changes/CHANGELOG.md)索引。名称含 `example` 的条目供填写时对照。
