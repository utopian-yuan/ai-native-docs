# 验证与证据

验证先对目标范围和环境，再选具体命令或复验步骤。每条证据包括版本、时间、身份、输入、环境、操作、结果和未覆盖项。模型或服务采用模拟件时记录所模拟的部分。

| 层级 | 证据覆盖 |
| --- | --- |
| D0 | 文档、来源、结构及静态约定 |
| D1 | 源码、静态检查、隔离单测 |
| D2 | 本机进程、接口或页面冒烟 |
| D3 | 数据库、对象存储、队列或其他依赖集成 |
| D4 | 真实入口和指定身份下的完整业务路径 |
| D5 | 冻结样本的质量、安全、性能或恢复评测 |
| D6 | 明确范围内的目标环境发布、回滚演练或客户验收 |

层级用于说明各单项结果的适用范围。工程验证通过后仍依据指定人员的决定更新验收状态。[验证报告模板](../reports/report-template.md)
