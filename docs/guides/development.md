# 团队开发、AI 协作与接手

1. 从 [工作约定](../../AGENTS.md) 和 [文档中心](../README.md) 找入口，核对 Git 工作区，再读当前任务涉及的局部规则。
2. 接已有任务先读 change 和未完成的任务行，核对最近证据与代码。新目标先填写验收条件，公示认领和依赖。
3. 多人分别在自己的分支推进，公共契约由提供方和消费者对齐。开工前把本项目启动、联调和测试命令及实际路径登记在这里。
4. 更新自己的任务行和证据，合入前同步目标分支并审阅差异。交接写明版本、未完成项、依赖和下一操作。
5. 换 AI 客户端时，显式引用 AGENTS.md 和同一个工作项，核对它能从证据重建已经做过的操作。阶段性交付按 [变更日志规则](../changes/README.md) 留痕。
