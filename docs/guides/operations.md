# 运行、部署、排障与回退

| 阶段 | 写入团队已核对的步骤 |
| --- | --- |
| 准备 | 目标环境、运行入口、依赖、产物版本、配置名及负责人 |
| 部署 | 实际发布和迁移入口、顺序、日志与健康检查位置 |
| 验证 | 服务状态、冒烟角色、主路径、失败时可观察到的信号 |
| 排障 | 从现象定位请求、时间窗、模块及可用检查 |
| 回退 | 触发条件、可回目标版本、恢复步骤、数据与权限对账 |

凭据从团队既有保管位置取得。实际执行写到 [发布记录](../releases/README.md)，数据回放、保留和恢复见 [数据运维](../data/operations.md)。
