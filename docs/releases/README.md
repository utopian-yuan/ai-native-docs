# 版本发布记录

发布负责人在版本进入某个约定环境时写一份记录，用版本或日期命名。读者应能回答“是哪套产物、进了哪里、谁验证过、出了问题退到哪里”。本地联调、测试试用和生产各写实际环境与范围。

| 发布前固定 | 发布后补记 |
| --- | --- |
| 候选版本、提交或构建号，包含哪些工作项、配置或迁移，采用哪个评审决定 | 实际时间、执行人、部署环境、身份和冒烟结果 |
| 回退版本、触发条件、操作顺序及恢复核对项 | 失败、未覆盖场景、遗留风险和签收来源 |

[工单看板 rc.2 发布实例](v0.4.0-rc.2-example.md) 保留了 rc.1 退回原因、rc.2 的三个冒烟结果和 0.3.0 的恢复入口。新的发布可以照这份记录另写。查个人改版走 [CHANGELOG](../changes/CHANGELOG.md)。
