# 发布记录模板

复制目录后填写发布日期、发布人、目标环境、版本、提交、产物来源和摘要。使用 [manifest](release-manifest.json) 保存机器可读信息。适用时在同目录保留构建生成的 SBOM，记录其来源与摘要。

| 核对项 | 实际记录 |
| --- | --- |
| 范围、环境、决定与评审 | 链接授权、评审、工作项和 CHANGELOG 条目 |
| 配置、迁移和备份 | 记录变动、兼容范围、执行顺序及恢复点 |
| 部署、冒烟和用户验证 | 记录执行时间、身份、依赖、结果和未覆盖项 |
| 回滚 | 版本、触发条件、恢复步骤、演练和对账结果 |
| 签收 | 确认人、验收范围、日期与决定 |
