# 按版本维护的系统设计图

这个目录服务于需要同时引用多张图的系统设计。由方案维护者按主题和版本组织源图及预览，给每张图写明确标题，例如「工单查询从页面到存储的调用顺序」。

| 登记项 | 应能回答的问题 |
| --- | --- |
| 方案版本与正文 | 哪一版设计引用这张图，读正文时点哪里 |
| 源图与预览 | 下一位编辑哪份，读者看哪份 |
| 适用范围及确认日期 | 图中哪些模块已实现，哪些仍在设计 |
| 替代关系 | 新图替代哪一版，旧版本怎样追溯 |

系统边界或接口改变后，先对照[技术方案](../../technical-design.md)，再一起更新图与正文。
