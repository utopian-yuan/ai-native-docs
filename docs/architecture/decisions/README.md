# 架构决策记录（ADR）

有多种可行方案，且决定会约束多个模块、版本或维护者时建 ADR。按仓库内的下一个编号创建条目，从 [ADR 模板](adr-template.md)写起。日常局部实现选型可以直接放工作项 design.md。

| 阶段 | 谁做什么 |
| --- | --- |
| proposed | 提案人记录约束、备选和代价，标明待谁决定 |
| accepted | 决定人确认采用范围、日期和依据，补实现工作项或契约 |
| superseded | 提供替代 ADR 的链接，在旧记录中保留当时适用的版本和理由 |

复查时先读决定状态，再沿链接看当前实现。移动或替换条目时核对所有引用。
