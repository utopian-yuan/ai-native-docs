# 跨模块契约

只要一个模块的输出被另一个模块或客户端依赖，就在这里登记维护源、版本和联系人。适用对象包括 API、事件、Agent 工具、权限语义及共享字段。

1. 提供方从实际实现或版本化 Schema 确认输入、返回、错误和身份语义，给出正常及边界样本。
2. 消费方说明按什么口径使用，升级时核对旧数据、异常与合入顺序。工作项 design 链接到契约正文。
3. 回归时按输入检查双方观察到的输出，实际结果放进工作项 evidence。

可从[契约模板](contract-template.md)起草。具体写法可参考教学案例里对 `mine`、当前会话和 `total` 的[约定](../../features/FEAT-20260511-example-my-open/design.md#流程与契约)。
