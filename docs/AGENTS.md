# 文档维护约定

阅读根 [AGENTS.md](../AGENTS.md) 和本目录的[导航](README.md)。进入工作项后，以其 change.md 的范围和证据来源为准。

- **先找维护人和位置。** 工作项保存本次目标、设计、分工和验证，architecture 保存长期契约，plan 管跨任务依赖，guides 保存可复做的操作。沿既有需求或原件入口引用原文。
- **写给下一位实际操作者。** 分类 README 说明何时用、谁来写、写哪些信息、从哪个文件或例子开始。工作项 README 用于导航，主状态只在 change.md 维护。
- **让实例可信。** 教学案例明确标注。涉及多人时，区分负责人、执行人、复审人和验收人。观察结果写到对应版本的证据。模拟决定仅用于教学。
- **保留团队选择的结构。** 用现有目录承载新内容。维护者明确删减或搬迁后，同时修正导航、相对路径和接入逻辑。历史证据保留适用日期和版本，迁移时核对入链与出链。
- **交付可追溯。** 每次改版按[日志规则](changes/README.md)署名，保留证据锚点和历史贡献。提交前检查相对链接、JSON 元数据、目录入口及 `git diff --check`。
