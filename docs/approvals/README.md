# 授权与决定

需要具名授权的操作在此登记，例如向指定环境发布、处理受限数据或对外发送材料。执行人先核对已有决定中的对象、环境、允许动作和有效时间。一般开发已获明确授权时，可以直接在工作项的 acceptance_ref 引用。

| 谁来写 | 需要保留的事实 |
| --- | --- |
| 决定人或代录人 | 结论、日期、适用对象和条件，能定位当事人原话的依据 |
| 执行人 | 实际操作的工作项、版本、环境和证据。超出原范围的部分留作待决 |
| 后续接手人 | 查看决定是否仍适用，沿工作项追到执行回执 |

使用[授权记录格式](approval-template.md)。评审意见记在[评审](../reviews/README.md)，两份记录可以相互引用。
